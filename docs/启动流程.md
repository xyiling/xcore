1. 写在rom中的固定代码

有一段固定的内存区域：0xffff0~0xfffff一共16字节，这里存放第一条指令：`jmp far f0000:e05b`

即第一条指令将pc值指向了`fe05b`这个内存地址。

> 为什么一共最多5个f(0xfffff)？
>> 5个f，扩展成二进制一共是5*4=20bits，代表20根地址线。 也即：实模式下，只支持20条地址线寻址

4. 启动位于磁道0盘0道1扇区的内容

为什么是0盘0道1扇区？

首先，计算机科学不是自然科学，它的所有内容都是认为规划的，因此没有为什么，一切都是可以修改的。但是有了规范后，都应该尽量遵循规范。

其次，CHS表示法的扇区号从1开始，LBA的扇区是从0开始的。

> 如何判断一个扇区内部是否有可执行的程序？
>> 假如扇区末尾两个字节分别是0x55 0xaa，按照规范就是可执行的

如果确定可执行，会默认加载到0x7c00，然后执行这段mbr程序。

> 为什么是0x7c00？
> - 首先，早期计算机将0x000~0x3ff硬性规定用来存放中断向量表
> - 其次，为给其他程序留空间，加之当时的计算机默认32kB内存，因而mbr被放到了最后一个字节，32kB换算成十六进制，为0x8000，减去1KB (0x400)，得到的就是0x7c00
