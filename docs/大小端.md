内存空间数值排布，上面是大地址，下面是小地址，如下：
```txt
0xffff+-------+
0xfffe|       |
...   |       |
0x0001|       |
0x0000+-------+
```
0x55aa
小端字节序：低字节放在小地址，高字节放在大地址，记忆：**小对低，大对高**

```txt
0xffff+-------+
0xfffe|       |
...   | 0x55  |
0x0001| 0xaa  |
0x0000+-------+
```


大端字节序：低字节放在**大**地址，高字节放在**小**地址
```txt
0xffff+-------+
0xfffe|       |
...   | 0xaa  |
0x0001| 0x55  |
0x0000+-------+
```
